# Gen I Glitch Preservation Project (G1GPP)

Private development repository for the Gen I Glitch Preservation Project, a Gen1Recomp mod focused on preserving authentic Pokémon Red/Blue glitch behavior while protecting the real save file from destructive original-game consequences.

## Repository role

This repository is the canonical home for version-controlled mod source, release-facing repository files, build scripts, and development history.

Internal project/source documentation is intentionally **not duplicated here**. The Project Bible, Development Handoff, TODO, focused research documents, publishing policy, emulator captures, recordings, VRAM/OAM/register dumps, debug logs, historical ZIP builds, and other research material remain canonical in the project Google Drive.

## Current status

The repository is private and pre-release. Current development source is under `trainer_fly/`.

The source currently reflects the private 12.13.50 development branch. Some runtime-derived image assets used by private test builds are intentionally **not** present in this repository. Their public-safe replacement must be generated from permitted Gen1Recomp/player-cache resources before release.

## Release-facing documentation

`README.md` and `DIFFERENCES.md` are maintained here because they are part of the eventual published repository/package. Internal planning and research documentation stays in Google Drive only.

## Private research archive

The separate Google Drive `Glitch Project` is the authoritative location for project documentation, emulator captures, binary evidence, videos, private test packages, and other research-only material.
