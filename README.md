# Gen I Glitch Preservation Project (G1GPP)

Public source repository for the Gen I Glitch Preservation Project, a
Gen1Recomp mod focused on preserving authentic Pokémon Red/Blue glitch behavior
while protecting the real save file from destructive original-game
consequences.

## Repository role

This repository is the canonical home for version-controlled mod source, release-facing repository files, build scripts, and development history.

Internal project/source documentation is intentionally **not duplicated here**. The Project Bible, Development Handoff, TODO, focused research documents, publishing policy, emulator captures, recordings, VRAM/OAM/register dumps, debug logs, historical ZIP builds, and other research material remain canonical in the project Google Drive.

## Current status

The first public candidate is `v1.0.0-beta`. Mod source is under
`g1gpp/`.

The public candidate promotes the accepted private 12.13.165 development
branch. The
Safari Zone save/reset Glitch City route is complete for Red/Blue, with the
shared implementation accepted through live Blue testing. Build 12.13.165
extends the validated stock and file-backed reversed-music window to twenty
source seconds, yielding roughly forty seconds at half speed and covering the
entire Glitch City phase without repetition. Build 12.13.164's recovered-map
NPC reload remains included and validated. Yellow-specific Safari validation
remains pending. Some
runtime-derived image assets are intentionally **not** distributed as extracted
files. Public-safe derived graphics are generated by `assets_transform.lua`
from the player's own imported Gen1Recomp cache.

## Compatibility and prerequisite

- Red and Blue gameplay are confirmed.
- Yellow is included as provisional support pending its dedicated validation.
- At least one of Gold, Silver, or Crystal must be imported into Gen1Recomp.
  Enable G1GPP for that Gen II edition and launch it once so the lawful
  asset-transform pipeline can derive Marill's graphics from the player's own
  cache. G1GPP gameplay remains inactive in Gen II.

## Public release status

The debug-free public packaging path and official validation gates are now in
place. The release-readiness audit and discovery workflow are maintained in
[`PUBLIC_RELEASE.md`](PUBLIC_RELEASE.md).

The short version is:

- G1GPP's no-ROM-content asset policy matches the current Gen1Recomp rules.
- The official captured-content lint currently passes.
- Official strict API-2 validation and captured-content lint pass against the
  exact staged public file set.
- The public ZIP uses the required root layout and excludes the development
  sentinel, debug menu modules, launch helpers, user-specific paths, and the
  redundant research encounter table.
- Build 12.13.165's longer reversed-audio window passed live stock and FRLG
  replacement-music testing without an apparent activation delay.

## Finding and installing G1GPP

Gen1Recomp now has a **Find Mods** launcher interface backed by community mod
indexes. G1GPP can be listed in the official community index after its public
repository and installable GitHub Release are ready. The index stores metadata
only; the mod remains hosted in this repository. With the manifest's `github`
field set, the launcher can discover new GitHub Releases and offer updates and
older versions.
