# Runtime asset note

This directory intentionally does **not** contain the private MissingNo front/back PNGs used by current research/test ZIPs.

Those images are treated as ROM-derived/research assets and must not be committed into Git history intended for eventual public release.

Before public release, the mod must generate or transform required glitch artwork from permitted Gen1Recomp/player-cache resources, or otherwise replace it with content that satisfies the upstream Gen1Recomp publishing guide.
